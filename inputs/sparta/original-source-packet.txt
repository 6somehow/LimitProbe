2: ## Overview
3: This branch is for the OSDI'22 artifact evaluation of paper "SparTA: Deep-Learning Model Sparsity via Tensor-with-Sparsity-Attribute". 
4: 
5: 
6: ## Evaluation Setup
7: * Artifacts Available:
8: The source code of Sparta is available at: https://github.com/microsoft/nni
9: 
10: * Artifacts Functional:
11: Documentation: the following document includes detailed guidelines on how to build, install, test Sparta and the experiments to compare with other baselines.
12: 
13: * Results Reproduced:
14: To reproduce the main results presented in our paper, we provide a Docker image containing all the environments and baseline softwares. We also provide detailed guideline to help reproduce the results step by step.
15: 
16: 
17: ## Environment setup
18: First, git clone the source code.
19: ```
20: git clone https://github.com/microsoft/nni
21: cd nni && git checkout sparta_artifact
22: ```
23: To make the reproducing easier, we provide a docker image that contains all dependencies and baselines. Build the docker image:
24: ```
25: cd image
26: sudo docker build . -t artifact
27: ```
28: Third, start a docker instance
29: ```
30: sudo docker run -it --gpus all --shm-size 16G artifact
31: ```
32: Following commands are executed in the docker.
33: First we also need get the source code and initialize the environment
34: ```
35: 
36: # install the sparta
37: mkdir workspace && cd workspace
38: git clone https://github.com/microsoft/nni && cd nni && git checkout sparta_artifact
39: conda activate artifact
40: python setup.py develop
41: # initialize the environment
42: cd script && bash init_env.sh
43: ```
44: ## Run the experiments
45: ### 2080Ti
46: We provide an end-to-end script to reproduce the experiment results of 2080Ti and A100. To reproduce the 2080Ti experiments with one command:
47: ```
48: bash run_all_2080ti.sh # current directory should be $SPARTA_HOME/script
49: ```
50: If you want to reproduce the figure in the paper one by one, you can first generate the checkpoints used in the following experiment and then go into the corresponding directory and execute `bash run.sh`
51: For example:
52: ```
53: bash init_checkpints.sh
54: # take figure13 for example
55: cd figure13 && bash run.sh
56: ```
57: The script will produce and draw the experimental data automatically. The generated pdfs are saved into corresponding directories.
58: 
59: 
60: ### A100
61: To reproduce the experiments on A100, we need to build a new docker image. The docker file of A100 environment is at `figure16/Dockerfile`. Once we build the docker image successfully, we
62: can also run the experiment with one script.
63: ```
64: bash run_all_a100.sh # current directory should be $SPARTA_HOME/script
65: ```
66: 
67: ### Note
68: If you need 2080Ti device during the artifact, please feel free to contact us.

20: def algebra_matmul(tesa_in1: TeSA, tesa_in2: TeSA) -> TeSA:
21:     """
22:     tesa_out = tesa_in1 * tesa_in2
23:     (m,n) = (m,k) * (k,n)
24:     """
25:     m, k = tesa_in1.tesa.size()
26:     n = tesa_in2.tesa.size()[1]
27:     tesa_out = TeSA(torch.zeros(m, n))
28:     for i in range(m):
29:         for j in range(n):
30:             tmp = Algebra(tesa_out.tesa[i][j])
31:             for x in range(k):
32:                 tmp += Algebra(tesa_in1.tesa[i][x]) * Algebra(tesa_in2.tesa[x][j])
33:             tesa_out.tesa[i][j] = tmp.val
34:     return tesa_out
