1: # Artifcat of the DX100 Paper, ISCA 2025
2: 
3: This repository provides the gem5 simulator, benchmarks, and automation scripts required for the artifact evaluation of the "DX100: A Programmable Data Access Accelerator for Indirection" paper published in ISCA 2025.
4: 
5: ## Directory Structure
6: 
7: The repo structure is as follows:
8:   - [src/mem/MAA](/src/mem/MAA/): gem5 source code of DX100.
9:   - [configs/common](/configs/common/): gem5 Python scripts for DX100 configuration.
10:   - [benchmarks](/benchmarks/): DX100 memory-mapped and functional simulator APIs, as well as the evaluated kernels from NAS, GAP, Hash-Join, UME, and Spatter benchmark suites.
11:   - [scripts](/scripts/): Automation scripts required for running the simulations, parsing the results, and plotting the charts.
12:   - [results](/results/): After running the automation scripts, raw results and charts are stored in this directory.
13: 
14: ## Requirements
15: 
16: This artifact has several dependencies. To simplify the evaluation process, we provide a Docker image with all required dependencies pre-installed. We recommend using the Docker container to minimize setup time and ensure a consistent environment.
17: 
18: ```bash
19: docker pull arkhadem95/dx100:latest
20: docker run -it --name dx100_container -v /path/to/data/dir:/data -w /home/ubuntu arkhadem95/dx100 bash
21: ```
22: 
23: *Note:* `/path/to/data/dir` should point to your data directory, which must have at least 20GB of available disk space.
24: 
25: If you choose to run the artifact locally instead of using Docker, please ensure the following dependencies are installed:
26: 
27: ### Ramulator2
28: 
29: Ramulator2 is tested with `g++-12` and `clang++-15` compilers.
30: 
31: ### gem5
32: 
33: gem5 requires the following dependencies (from [gem5 documentations](https://www.gem5.org/documentation/general_docs/building)):
34: 
35: - SCons: gem5 uses SCons as its build environment. SCons 3.0 or greater must be used.
36: - Python 3.6+: gem5 relies on Python development libraries. gem5 can be compiled and run in environments using Python 3.6+.
37: - protobuf 2.1+ (Optional): The protobuf library is used for trace generation and playback.
38: - Boost (Optional): The Boost library is a set of general purpose C++ libraries. It is a necessary dependency if you wish to use the SystemC implementation.
39:

25: ## How to rewrite a kernel using MAA APIs?
26: 
27: ### Single loop
28: 
29: If the loop does not start from `0` with the stride of `1`, *e.g.*:
30: 
31: ```C++
32: for (int i = min; i < max; i += stride) {
33: }
34: ```
35: 
36: Convert it to:
37: 
38: ```C++
39: int i_max = (max - min - 1) / stride + 1;
40: for (int i = 0; i < i_max; i++) {
41:     int real_i = i * stride + min;
42: }
43: ```
44: 
45: Where new `i` iterates from `0` to `i_max` with `stride = 1`.
46: If needed, you can calculate the value of previous `i` iterator (`real_i`) which iterates from `min` to `max` with `stride`.
47: 
48: For tiling, convert the previous loop into 2 nested loops.
49: The outer loop iterates on tiles, and the inner loop iterates on the individual iterations of the tile.
50: 
51: ```C++
52: int i_max = (max - min - 1) / stride + 1;
53: for (int i_base = 0; i_base < i_max; i += TILE_SIZE) {
54:     for (int i_offset = 0; i_offset < curr_tile_size; i_offset++) {
55:         int curr_tile_size = min(i_max - i_base, TILE_SIZE);
56:         for (int i_offset = 0; i_offset < curr_tile_size; i_offset++) {
57:             int i = i_base + i_offset;
58:             int real_i = i * stride + min;
59:         }
60:     }
61: }
62: ```
63: 
64: ### Single loop + direct range loop
65: 
66: For example:
67: 
68: ```C++
69: for (int i = min; i < max; i += stride) {
70:     for (int j = boundaries[i]; j < boundaries[i + 1]; j++) {
71:     }
72: }
73: ```
74: 
75: First, convert the outer loop to a new outer loop iterating from `0` to `i_max` with `stride = 1`:
76: 
77: ```C++
78: int i_max = ceil((max - min) / stride);
79: for (int i = 0; i < i_max; i++) {
80:     int real_i = i * stride + min;
81:     for (int j = boundaries[real_i]; j < boundaries[real_i + 1]; j++) {
82:     }
83: }
84: ```
85: 
86: Second, tile the outer loop:
87: 
88: ```C++
89: int i_max = ceil((max - min) / stride);
90: for (int i_base = 0; i_base < i_max; i += TILE_SIZE) {
91:     int curr_tile_size = min(i_max - i_base, TILE_SIZE);
92:     for (int i_offset = 0; i_offset < curr_tile_size; i_offset++) {
93:         int i = i_base + i_offset;

95:         for (int j = boundaries[real_i]; j < boundaries[real_i + 1]; j++) {

97:     }
98: }
99: ```
