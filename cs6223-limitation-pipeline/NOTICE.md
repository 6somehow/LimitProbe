## Before making this repository public

1. **Datasets and labels.** Remove `data/limitset/` and `data/limitset2/` labels, or get written permission
   from the dataset owner. The code works with the raw dataset obtained separately.
2. **Teammate contributions.** The MIT license names "the CS6223 project contributors". Every contributor
   (including the authors of `paperside/` and `checklimits/`) must agree to that license, or their directories
   must be excluded.
3. **Imported code without a license** (`paperside/tools/papertest-swarm`): ask the author to add one, or remove it.
4. **Quoted excerpts** in `results/` and `paperside/`: check them against the publishers' terms, or drop the files.
5. **Local paths and history.** About 80 recorded outputs contain absolute paths of the author's machine. The
   git history contains the full development record, including large generated test artifacts.
6. **Credentials.** None are committed (the history was scanned for key-shaped strings; the only hit is a dummy
   value in a test). Keep keys in the environment of the local relay only.
