# CS6223 方法限制参考判据（评估专用）

来源：Shanghao 11 月 21 日《论文方法的限制主张与判断逻辑》。本文件保存机制、后果和反证条件的简写。模型的工具范围不包含这个文件或来源文档。候选原文锁定后再评分。01–04 为开发案例；05、07、09、11、13、14、16、17 为团队初筛新增案例；06、08、10、12、15 保留待复核，不进入主结果分母。

| 编号 | 论文 | 核心机制与后果 | 关键限制、反证或所需对照 |
|---|---|---|---|
| 01 | NNSmith | 首次有限执行即停，不主动覆盖其余合法数值区域。合法取值依赖的缺陷可能漏过。 | 随机初始化、修复及重启可增加多样性。固定图和资源，比较首次成功、独立重启以及覆盖引导；直接量合法数值覆盖。 |
| 02 | MInference | 长上下文扩展或动态位置缩放改变 RoPE 映射，重要注意力可能分散到更多斜线。固定模式和预算的在线索引不足以恢复覆盖。 | 比较固定模型、输入和预算下的稠密参考、原稀疏配置与重校准。证明所需预算和近似误差确有变化；只发现分数或位置变化属于部分线索。 |
| 03 | InfiniGen | 逐头预测变换遇到 GQA 多个查询头共享一个键表示。当组内低维压缩需要不同基时，共同基可能要增加维度或降低预测质量，而逐头部分表示增加成本。 | 检查在实际键方向上的差异。不能由矩阵不同推出无法共享，不能假定复制完整 K 或 V。 |
| 04 | SparTA | 额外传播取决于零值分布能否切断真实依赖。非结构化零即使占比高，也可能保留归约依赖。 | 固定稀疏率变换排列；区分传播新增零与端到端速度。原文 Figure 14 是作者披露的证据。 |
| 05 | Prompt Cache | 独立预计算的模块 KV 缺少前序模块条件关系，位置对齐无法补回。跨模块依赖强时需要联合缓存或重算而侵蚀复用。 | 有效答案质量必须实际依赖缺失的表征；后续查询如果能充分恢复，影响会减弱。 |
| 07 | SpinQuant | 共享残差旋转 R1 便于吸收部署，但各层若需要不同基来降低量化误差，公共基迫使折中。 | 检验逐层 R2 等自由度有无吸收冲突。仅各层分布不同不足以推出损失。 |
| 09 | KVQuant | 首 token 的高精度保护以位置代理敏感性，敏感状态若在其他位置且异常值隔离未覆盖，预算会保护错对象。 | 对齐同精度预算的固定首位与自适应保护，检查首位之外误差及既有异常值保护。只发现非首位汇聚不是完整命中。 |
| 11 | OneSidedMW | 单计算节点所有权会约束共享状态访问位置，削弱任务放置和所有权独立调度的自由度。 | 性能后果取决于应用是否真需独立调度；天然按键归属路由的场景可能不受影响。 |
| 13 | CXLfork | 共享快照降低容量，但实例各自读取可竞争同一通路。局部热度和延迟驱动的分层可能忽略流量累积。 | 检查共享通路是否实为瓶颈且已有分层或缓存不能吸收。容量改善与延迟改善分别测量。 |
| 14 | DX100 | 跨迭代依赖阻止重要间接访存核卸载；被挡下的核若占主要时间，独立核加速未必带来应用端收益。 | Gauss–Seidel 只建立排除机制。是否重要取决于依赖核的时间占比。 |
| 16 | Juneberry | 写 ACK 先返回，实际执行仍在后台。当依赖读/更新在执行完成前到来，剩余执行重新进入业务关键路径。 | 控制请求依赖到达的时间间隔；独立工作若已覆盖后台执行，端到端影响减弱。 |
| 17 | Twilight / T-LITE | 小模型降低预取推理成本，但净能耗取决于推理次数与及时且被消费的预取所节省的能耗。加速不保证净能耗收益。 | 能耗必须是部署目标。程序稳定性与净能耗门槛分开；对照推理和节省的实际能耗。 |

评分单位为最后保留的一条候选或作者边界记录。命中核心要求机制、前提及后果可对应；仅找到其中一段或用相同机制得到不同后果分别注明部分/未命中。额外检查反证、可测对照、引用及实现链，避免将原理推断算作运行确认。没有代码时只给论文级匹配，单列统计。
